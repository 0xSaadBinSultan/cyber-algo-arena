Signal Surge

Given a sequence of signal changes, find the largest possible sum of a non-empty contiguous subarray. Signal Surge is a maximum subarray problem: the chosen values must be consecutive, and at least one value must be selected.

Solve Signal Surge in the arena ↗

Problem statement

A satellite transceiver receives a continuous telemetry stream of signal delta measurements. A power surge occurs over the contiguous transmission interval that maximizes the cumulative sum of signal deltas. Find the maximum possible sum of a non-empty contiguous subarray.

Input

The first line contains n, the number of measurements (1 ≤ n ≤ 100000). The second line contains n integers aᵢ (−10⁹ ≤ aᵢ ≤ 10⁹).

Output

Print a single integer: the maximum sum among all non-empty contiguous subarrays. Use a 64-bit integer in C++ or Java.

Sample 1

Input

9
-2 1 -3 4 -1 2 1 -5 4

Output

6

The interval 4, −1, 2, 1 has sum 6.

Sample 2

Input

5
5 4 -1 7 8

Output

23

Here, choosing the entire sequence gives the largest sum.

Can the answer be negative?

Yes. The subarray must be non-empty. If every value is negative, selecting no values and returning zero is incorrect. Think about the best interval ending at each position and how to track the best one seen so far.

Submit and evaluate

The built-in problem has two public samples and six hidden tests, a 2-second time limit, and a 256 MB memory limit. Open Signal Surge in the problemset and submit in C++, Java, or Python. The judge evaluates the solution against every configured testcase.

For an easier first problem, try Packet Budget. The CP guide explains judge verdicts.
