Packet Budget

Given n packet sizes, print their total size. Packet Budget is a beginner competitive programming problem about reading input, summing numbers, and choosing an integer type large enough for the answer.

Solve Packet Budget in the arena ↗

Problem statement

Your university network records the size of every packet in a batch. Calculate the total number of bytes in the batch.

Input

The first integer is n, the number of packets (1 ≤ n ≤ 200000). The next n integers are packet sizes aᵢ (0 ≤ aᵢ ≤ 1000000000). Integers may be separated by any whitespace.

Output

Print one integer: the sum of all packet sizes.

Sample 1

Input

5
12 8 5 10 15

Output

50

The total is 12 + 8 + 5 + 10 + 15 = 50 bytes.

Sample 2

Input

3
0 0 7

Output

7

What should I watch out for?

The answer can exceed 2147483647. Use a 64-bit integer such as long long in C++ or long in Java. Python integers can represent the total. Aim for O(n) time and use standard input and output.

Submit and evaluate

The built-in problem has two public samples and six hidden tests, a 2-second time limit, and a 256 MB memory limit. Open Packet Budget in the problemset, select C++, Java, or Python, and sign in to submit. Hidden inputs and outputs are not published on this page.
