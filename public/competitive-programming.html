Cyber Algo Arena/The Cp Field Guide

THE CP FIELD GUIDE

Learn competitive programming, one problem at a time.

Competitive programming (CP) is the practice of solving algorithmic problems with code under time and memory limits. Cyber Algo Arena lets you submit C++, Java, and Python solutions and evaluate them against public samples and hidden testcases.

Open the CP problemset ↗

How does the online judge work?

Read the input format, write a program that reads standard input, and print the required result to standard output. The judge compiles or runs your source code for each testcase and compares the result with the expected output.

A correct sample is a useful first check. Hidden tests also cover cases such as zero values, large numbers, unusual whitespace, and larger inputs. Passing the samples alone does not mean a solution is correct.

What do the verdicts mean?

Accepted
The solution passed every configured testcase.
Wrong Answer
The program ran, but at least one result did not match the expected answer.
Compilation Error
The compiler could not build the submitted source.
Runtime Error
The program stopped unexpectedly, for example after an invalid array access.
Time or Memory Limit Exceeded
The solution exceeded a resource limit. Revisit the algorithm and the input constraints.

Which languages can I use?

The arena’s CP judge supports C++, Java, and Python. Choose the language in the problem workspace before submitting. Use standard input and output; Java submissions should use the Main class.

A practical learning loop

  1. Work through the samples by hand.
  2. Estimate the largest input and choose an algorithm that fits.
  3. Test boundary cases, including the smallest valid input.
  4. Run the public samples, then submit for hidden-test evaluation.
  5. Read the verdict and improve the solution.
